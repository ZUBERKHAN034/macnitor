# Communication preferences

- Reads documentation and code fully before writing any code ("read before writing — do not skip"). Confidence: 0.9
- Treats code as the source of truth over documentation; when they conflict, resolve from the code and report the discrepancy before designing. Confidence: 0.95
- Prefers to be stopped and asked rather than have an agent guess when something contradicts the instructions. Confidence: 0.95
- Prefers a short, bounded written research summary before moving to design (e.g. max one page). Confidence: 0.85
- Prefers a structured final report: current behavior with file paths, research summary, design + file list, implementation in small commits, test results + manual QA checklist, and open questions/risks. Confidence: 0.85
- Asks for an explicit verification pass over changes (is it correct?) before finalizing/building, and wants the verification result reported. Confidence: 0.75
